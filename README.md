# Алиса + ChatGPT

Навык Яндекс Алисы: вопрос пользователя уходит в ChatGPT (OpenAI API), ответ звучит в колонке.
Без зависимостей, нужен Node.js 18+.

## Деплой на Railway

1. New Project → Deploy from GitHub repo → выбрать этот репозиторий.
2. Variables → добавить `OPENAI_API_KEY` = ваш ключ OpenAI.
3. Settings → Networking → Generate Domain. Получится адрес вида `https://gpt-alice.up.railway.app`.
4. Открыть адрес в браузере — должно быть `Alice ChatGPT skill is running`.

## Подключение к Алисе

1. https://dialogs.yandex.ru/developer → Создать диалог → Навык.
2. Backend → Webhook URL → адрес из Railway.
3. Заполнить имя активации (например, «Чат Джи Пи Ти»), описание, иконку → протестировать во вкладке «Тестирование».
4. Отправить на модерацию или оставить приватным (доступен только вам — удобно для своей колонки).

В колонке: «Алиса, запусти навык Чат Джи Пи Ти» → задаёте вопросы → «хватит» для выхода.

## Как работает ожидание

Алиса ждёт ответ навыка ~3 секунды. Если ChatGPT не успел, навык говорит
«Секунду, ChatGPT думает. Скажите „дальше“», а запрос продолжает выполняться.
По слову «дальше» звучит готовый ответ.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `OPENAI_API_KEY` | — | ключ OpenAI (обязательно) |
| `OPENAI_MODEL` | `gpt-4o-mini` | модель |
| `SYSTEM_PROMPT` | короткие ответы для голоса | инструкция для ChatGPT |
| `ANSWER_TIMEOUT_MS` | `2500` | сколько ждать ответа до «скажите дальше» |
| `MAX_HISTORY` | `10` | сколько сообщений диалога помнить |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | для прокси/совместимых API |
